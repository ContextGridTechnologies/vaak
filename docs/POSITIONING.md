# Positioning

## Category

Open-source voice layer for desktop work.

## Short Description

Vaak turns speech into polished text and inserts it into the app the user is
already using.

## Core Message

Speak once. Get clean text anywhere. Keep control of your models and data.

## Public Positioning Statement

Vaak is open-source voice tooling for desktop workflows. It is local-first by
default, supports bring-your-own-model providers, and offers optional managed
cloud features for users and teams who want convenience.

## Pricing Position

Vaak should not require a recurring subscription for the core desktop product.
The user chooses between:

- local mode with their own provider key, free to Vaak
- optional managed transcription at a target rate of `$1 per 60 minutes`

The managed rate is a simple usage unit, not a `$1` checkout. Credits should be
sold in practical top-ups such as `$5 for 300 minutes` and `$10 for 600
minutes`, without automatic renewal. Until managed billing is live, public copy
must label this path as coming soon.

## Audience

Initial audience:

- developers
- founders
- operators
- writers
- support teams
- people who type repetitive text all day

Later audience:

- teams with shared vocabulary
- companies with privacy requirements
- organizations that want managed deployment and billing

## Differentiation

Vaak should lead with:

- open source
- local-first usage
- provider choice
- desktop-wide insertion
- extensibility
- optional managed cloud
- team vocabulary and governance later

Vaak should not lead with:

- reactive market language
- price-only positioning
- another company's product category as the product's reason to exist
- generic AI assistant language
- vague productivity claims

## Messaging Pillars

### User Control

Users choose local mode, BYO providers, or managed cloud.

### Works Where You Work

The product inserts text into the user's active desktop app.

### Open And Extensible

Developers can inspect, run, modify, and extend the product.

### Practical AI

AI is used to clean up, rewrite, format, and adapt dictated text.

### Business-Ready Later

Paid value comes from sync, managed usage, teams, admin controls, and support.

and quality bars. Public identity should be built around Vaak's own category:
open-source voice tooling for desktop workflows.
